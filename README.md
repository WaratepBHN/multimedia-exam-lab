# MM Study Lab

เว็บภาษาไทยสำหรับทบทวน 06016403 Multimedia Technology บท 6–12

- สรุปเส้นทางอ่านประมาณ 10 นาที โดยให้น้ำหนักบท 8 และ 10
- หน้า `graphics.html` เพิ่มเนื้อหาบท 6 2D & 3D Graphics พร้อมภาพและตัวอย่าง โดยไม่มีข้อสอบบท 6
- หน้า `audio.html` อธิบาย lossless / lossy, predictive coding, masking, bit allocation และตัวอย่างข้อเขียน
- หน้า `web.html` อธิบาย HTML, DOM, DOM API, renderer, Web Worker และ WCMS
- คลัง 50 ข้อ ดัดแปลงแนวโจทย์จากสไลด์และแบบฝึกเดิม สุ่มครั้งละ 30 ข้อพร้อมสลับตัวเลือก
- ตรวจคะแนนรายบทและเฉลยพร้อมเหตุผลทุกตัวเลือก
- ภาพประกอบ SVG วาดใหม่ รองรับ desktop/mobile และ reduced motion

## รันในเครื่อง

ใช้ Node.js โดยไม่ต้องติดตั้ง dependencies:

```sh
npm start
```

เปิด `http://127.0.0.1:4173` และตรวจระบบสุ่ม/คะแนนด้วย `npm test`

บท 6 เป็นเนื้อหาอ่านทบทวนเท่านั้น คลังแบบฝึกยังมี 50 ข้อจากบท 7–12 และสุ่มครั้งละ 30 ข้อตามเดิม

## เผยแพร่

เป็น static HTML/CSS/ES modules ใช้ GitHub Pages จาก `main` และโฟลเดอร์ `/ (root)` ได้โดยตรง มี `.nojekyll` และใช้ relative paths รองรับ project Pages URL

เนื้อหาเรียบเรียงจากสไลด์อาจารย์และหนังสือประกอบ รายละเอียดหน้าอ้างอิงและจุดที่ตรวจความแม่นยำอยู่ใน `sources.html` ไม่ได้เผยแพร่ PDF หนังสือ/สไลด์ ภาพคะแนน หรือข้อมูลส่วนบุคคล

แบบฝึกไม่ใช่ข้อสอบจริง และคะแนนของชุดสุ่มไม่ใช่การรับรองความพร้อมของการสอบ
